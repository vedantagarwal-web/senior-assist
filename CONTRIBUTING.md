# Contributing to SeniorAssist

Thanks for your interest in contributing! This project aims to make technology accessible for seniors.

## 🚀 Quick Start

1. Fork the repo
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/senior-assist.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test thoroughly (see TEST.md)
6. Commit: `git commit -am "Add your feature"`
7. Push: `git push origin feature/your-feature-name`
8. Open a Pull Request

## 📋 Guidelines

### Code Style
- Use ESLint/Prettier configs provided
- Write descriptive commit messages
- Add comments for complex logic
- Keep functions small and focused

### Testing
- Test voice flow end-to-end before submitting
- Add unit tests for new backend logic
- Verify browser automation still works
- Check mobile responsiveness for frontend

### Documentation
- Update README.md if adding features
- Add comments to complex code
- Update SETUP.md if changing dependencies
- Document API changes

### Accessibility
- This project serves seniors — keep UX simple
- Test with screen readers
- Use high contrast, large fonts
- Avoid jargon in voice prompts

## 🐛 Bug Reports

Use GitHub Issues. Include:
- Description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Screenshots/logs if applicable
- Environment (OS, Node version, etc.)

## 💡 Feature Requests

Open a GitHub Issue with:
- Problem you're solving
- Proposed solution
- Why it helps seniors/caregivers
- Any implementation ideas

## 🤝 Code of Conduct

- Be respectful and inclusive
- Assume good intentions
- Focus on the mission: helping seniors
- No harassment, discrimination, or trolling

## 📞 Questions?

- Open a GitHub Discussion
- Tag @vedantagarwal-web in issues
- Check existing docs first (README, SETUP, TEST)

Thanks for making technology more accessible! ❤️
